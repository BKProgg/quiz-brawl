# 전자금융개발 퀴즈 대회

10명 내외가 브라우저에서 즐기는 업무 퀴즈 난투 게임입니다. 캐릭터끼리 싸우면서 바닥의 정답 구역을 차지하고, 카운트가 끝나는 순간 정답 구역 안에 있으면 점수를 얻습니다.

- 서버: Cloudflare Workers + Durable Objects (무료 플랜)
- 클라이언트: TypeScript + Canvas 2D
- 스펙: [specs/quiz-brawl-game.md](specs/quiz-brawl-game.md)

## 접속 주소 (배포본)

| 용도 | 주소 |
|---|---|
| 플레이어 | https://quiz-brawl.efin-quiz.workers.dev |
| 관리자 | https://quiz-brawl.efin-quiz.workers.dev/admin |

참가자에게는 플레이어 주소만 공유합니다. 관리자 주소에도 인증이 없어, 주소를 아는 사람은 누구나 게임을 시작·중단할 수 있습니다.

## AI 봇과 혼자 해 보기

사람이 모이지 않아도 10명 난투를 해 볼 수 있습니다. 봇 9명을 넣고 남은 한 자리로 직접 들어갑니다.

```bash
node scripts/run-brawl-bots.mjs
```

1. 위 명령을 실행하면 봇 9명이 배포본 대기실에 들어와 싸우기 시작합니다.
2. 플레이어 주소를 열어 닉네임을 쓰고 남은 캐릭터를 고릅니다.
3. 다른 탭에서 관리자 주소를 열고 "게임 시작"을 누릅니다.
4. 한 판이 끝나면 관리자 화면에서 "새 게임"을 누릅니다. 봇은 7~8초 뒤에 다시 들어오니 그 전에 캐릭터를 먼저 고릅니다.

- 봇은 가장 가까운 상대를 쫓아가 주먹·발차기·들어 던지기를 섞어 쓰고, 물건을 주워 던집니다. 정답은 모르고, 판정 7초 전부터 아무 칸이나 골라 달려갑니다.
- 30분 뒤 자동으로 나갑니다. 바로 끝내려면 Ctrl+C를 누릅니다.
- 주소·봇 수·실행 시간(분)을 차례로 붙여 바꿀 수 있습니다. 아래는 로컬 서버에 봇 5명을 10분간 넣는 예입니다.

```bash
node scripts/run-brawl-bots.mjs http://127.0.0.1:8787 5 10
```

- **행사 전에는 봇을 반드시 끕니다.** 봇도 정원(10명)을 차지합니다.

## 로컬 실행

```bash
npm install
```

```bash
npm run dev
```

- 플레이어: `http://127.0.0.1:8787` — 닉네임(최대 5글자)을 쓰고 12색 중 캐릭터를 고르면 바로 입장합니다. 탭을 여러 개 열면 여러 명으로 테스트할 수 있습니다.
- 관리자: `http://127.0.0.1:8787/admin` — 경기장 관전 화면. 게임 시작, (진행 중) 게임 중단, (최종 결과 화면에서) 새 게임 버튼은 여기에만 있습니다. 큰 화면에 띄워 두기 좋습니다.
- 인증이나 입장 코드는 없습니다. 주소를 아는 사람은 누구나 들어올 수 있습니다.
- 문제 파일 `src/server/questions.json`은 git에 올리지 않습니다. 처음 받은 뒤 `npm install`을 하면 예시 문제가 복사되므로, 실제 문제로 바꿔 넣고 쓰세요.

## 조작법

| 키 | 동작 |
|---|---|
| 방향키 | 이동 |
| Z | 주먹 (아이템 위에서는 줍기, 들고 있으면 던지기) |
| X | 발차기 |
| C | 막기 (누르고 있기) |
| 상대에게 붙어서 상대 방향키 + Z | 머리 위로 들기. 다시 Z를 누르면 바라보는 방향으로 던지기 |

체력은 없고, 1.5초 안에 3대를 맞으면 뒤로 날아가 쓰러집니다(1초 다운 + 1초 무적). 10~20초마다 좌우 벽에서 굴러오는 거대한 통나무는 막기로 못 막으니 위아래로 피하세요.
문제마다 판정 5~8초 전에는 메테오가 한 번 떨어집니다. 주황색 경고 원이 2초 동안 차오른 뒤 떨어지고, 원 안에 있으면 중심 반대 방향으로 날아가 1.5초 동안 별을 보며 쓰러집니다. 역시 막기로 못 막으니 원 밖으로 달리세요.
상대를 든 동안에는 천천히 걸으며 방향을 고를 수 있습니다. 1.5초 안에 던지지 않으면 들린 사람이 빠져나옵니다. 든 사람이 맞거나 다른 사람에게 잡히면 들린 사람은 안전하게 내려와 1초 동안 무적입니다.
판정 순간 정답 칸 위에 있으면 날아가는 중이든 들려 있든 쓰러져 있든 모두 득점합니다.
입장하면 반투명 키보드 안내가 10초간 보이고, Esc나 Enter로 닫을 수 있습니다.

## 게임 진행

관리자가 시작하기 전 대기실에서는 자유 난투를 합니다. 시작하면 5초 카운트 뒤 문제 6개(OX / 4지선다)가 무작위 순서로 차례로 나옵니다. 문제마다 30초가 끝나는 순간 정답 칸 위에 있으면 100점이고, 마지막 5초는 화면이 붉어지며 큰 숫자로 셉니다. 정답 칸은 경기장을 꽉 채우는 격자입니다.
마지막 문제 뒤에는 1위 시상대·왕관·꽃가루와 꼴찌(공동이면 전원)의 우는 연출이 나오고, 최종 화면은 관리자가 "새 게임"을 누를 때까지 유지됩니다. "새 게임"(진행 중에는 "게임 중단")을 누르면 전원이 내보내져 각자 닉네임·캐릭터 선택부터 다시 시작합니다.

## 연결이 끊기면

- 게임 중 끊기면 서버가 15초 동안 자리·점수·색을 유지하고, 브라우저가 1.5초마다 최대 12번 자동으로 다시 붙어 같은 자리로 돌아옵니다(시도 하나는 4초 안에 안 열리면 버립니다). 끊긴 채 판이 끝나도 최종 순위에 들어갑니다.
- 12번을 다 실패해도 화면을 누르거나 키를 누르면 다시 시도합니다. 처음 접속과 관리자의 새 게임·중단 뒤 재연결도 같은 방식으로 여러 번 시도합니다.
- 서버 소식(핑 응답 포함)이 8초 동안 오지 않으면 브라우저가 스스로 끊고 다시 붙습니다(와이파이 끊김 대비). 관리자 화면도 같습니다.
- 서버는 10초 동안 소식이 없는 사람의 방향키·막기를 뗀 것으로 보고(캐릭터가 혼자 달리지 않게), 70초 동안 소식이 없으면 연결을 끊습니다.
- 캐릭터 선택 화면에 2분 넘게 머물면 서버가 연결을 쉬게 합니다. 화면을 누르거나 탭을 다시 보면 자동으로 붙어 바로 고를 수 있습니다. 대기실(게임 시작 전)에서 끊기면 자리는 사라지고 다시 고르게 됩니다.
- 뒤로 숨긴 탭도 서버 메시지를 받을 때마다 핑을 보내므로 연결이 유지됩니다. 자동으로 안 붙으면 새로고침을 안내하세요.
- 같은 자리로 다른 탭이 들어오면 먼저 열린 탭은 물러납니다. 관리자 화면은 2초마다 계속 다시 붙습니다.

## 배포 (Cloudflare 무료 플랜)

처음 한 번은 Cloudflare 로그인이 필요합니다.

```bash
npx wrangler login
```

```bash
npm run deploy
```

배포하면 `https://quiz-brawl.<서브도메인>.workers.dev`(플레이어)와 같은 주소 뒤에 `/admin`(관리자)으로 접속합니다. 별도로 설정할 비밀 값은 없습니다.

게임 방(Durable Object)은 `src/server/worker.ts`의 `locationHint: 'apac'` 덕분에 아시아에 만들어집니다(서울 기준 왕복 30~70ms). 특정 참가자만 유난히 느리면 그 사람의 접속이 먼 센터로 잡힌 것이니 새로고침하면 대개 풀립니다.

## 운영 수칙

- **행사 중에는 배포하지 않습니다.** 서버가 재시작되면 전원이 끊기고 진행 중인 판이 초기화됩니다.
- **행사 시작 30분 전부터는 배포도 `wrangler tail`(서버 로그 보기)도 하지 않습니다.** 실측으로 둘 다 약 5분 뒤에 서버가 한 번 재시작됐습니다(전원 끊김, 방 초기화).
- **행사 외 시간에는 관리자 탭을 닫습니다.** 접속이 남아 있으면 서버가 깨어 있어 무료 활성 시간을 씁니다.
- 인터넷 구간에서 연결 하나가 잠깐 끊기는 일은 가끔 있습니다(실측: 6분짜리 판에서 11개 연결 중 0~3개). 브라우저가 1.5초 뒤 같은 캐릭터·점수로 알아서 돌아오므로 기다리면 됩니다. 돌아오지 않으면 새로고침하도록 안내합니다.
- **시작 전에 관리자 화면의 참가자 수가 인원과 맞는지 확인합니다.** 캐릭터 선택 화면에 머물러 있거나 시작 뒤에 들어온 사람은 그 판을 구경만 합니다.
- 정원은 10명이고 여유가 없습니다. 시험 삼아 연 플레이어 탭은 닫아 두세요. 게임 중 탭을 닫고 새 탭으로 오면 15초 동안 "방이 가득 찼습니다"가 뜹니다(닫은 탭 다시 열기나 새로고침은 같은 자리로 돌아옵니다).
- 새 게임·게임 중단 확인 창은 오래 띄워 두지 않습니다(70초를 넘기면 관리자 연결이 끊겨 다시 눌러야 합니다).
- 무료 플랜 한도는 하루 요청 10만 건·Durable Object 활성 13,000 GB-s이고, 매일 한국 시간 09:00에 초기화됩니다. 실측으로 10명이 1시간 내내 플레이해도 요청 약 1만 5천 건, 활성 약 500 GB-s 수준입니다.

## 창 10개 자동 리허설

Chrome 창 10개 + 관리자 창을 띄워 입장부터 최종 결과·새 게임·끊김·게임 중단까지 자동으로 돌리고, 서버 상태의 불변식과 브라우저 오류를 검사합니다(macOS, Google Chrome 필요, 약 6분).

```bash
node scripts/brawl-test/run-brawl-test.mjs https://quiz-brawl.efin-quiz.workers.dev
```

- 주소를 생략하면 로컬 서버(`http://127.0.0.1:8787`)를 검사합니다. 두 번째 인자로 결과 폴더를 줄 수 있고, 생략하면 임시 폴더에 화면 캡처와 `summary.json`이 남습니다.
- 배포본을 검사하면 그동안 방이 사용 중이 되므로, 사람들이 접속하기 전에만 돌립니다.
- 다른 무거운 작업(큰 다운로드·설치)과 함께 돌리면 검사 쪽 PC가 멈칫해 "상태가 너무 오래 지속됨"이 잘못 잡힐 수 있습니다.

## 폴더 구조

| 폴더 | 내용 |
|---|---|
| `src/game/` | 서버·클라이언트 공용 게임 규칙 (순수 함수, 단위 테스트 대상) |
| `src/server/` | Worker 진입점, Durable Object(방), 매치 진행, 메시지 검증 |
| `src/client/` | 입력, 네트워크·재접속, 보간·예측, 렌더링, 입장·관리자 화면 |
| `public/` | 정적 파일, 가공된 이미지(`public/assets/`) |
| `scripts/` | AI 생성 이미지 가공 스크립트, AI 봇 실행 스크립트(`run-brawl-bots.mjs`), 창 10개 자동 리허설(`brawl-test/`) |
| `mockups/` | 초기 비주얼 목업 (참고용) |
