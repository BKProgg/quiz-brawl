# 전자금융개발 퀴즈 대회 — 사용 기술

브라우저에서 최대 10명이 동시에 접속해, 캐릭터끼리 싸우며 바닥의 정답 구역을 차지하는 실시간 퀴즈 게임입니다.
설치나 로그인 없이 링크만 열고 닉네임과 캐릭터를 고르면 됩니다.

## 한눈에 보기

| 구분 | 사용 기술 |
|---|---|
| 언어 | **TypeScript** (서버·브라우저 공통), HTML, CSS |
| 서버 | **Cloudflare Workers + Durable Objects** (무료 플랜) |
| 실시간 통신 | **WebSocket** |
| 화면 | **HTML5 Canvas 2D** — 게임 엔진·프레임워크 없이 직접 그림 |
| 그래픽 | **AI 이미지 생성** 도구로 캐릭터·배경·소품 제작 |
| 개발 도구 | esbuild(번들), Wrangler(로컬 실행·배포), Vitest(테스트), Claude Code(AI 코딩 도구) |

## 구조

```
브라우저(플레이어 최대 10명 + 관리자 화면)
   │  WebSocket (입력은 보내고, 게임 상태는 받음)
   ▼
Cloudflare Worker  ──▶  Durable Object (게임 방 1개)
                         · 이동·타격·판정을 서버가 직접 계산 (초당 30번)
                         · 모든 참가자에게 상태 전송 (초당 20번)
```

- **서버 권한 방식**: 플레이어는 "어떤 키를 눌렀는지"만 보냅니다. 누가 맞았는지, 누가 정답 구역에 있는지는 서버가 판정합니다.
  그래서 브라우저를 조작해도 점수를 속일 수 없고, 정답은 판정 순간 이후에만 전송됩니다.
- **게임 시작은 관리자 화면에서만**: 게임 시작, 게임 중단, 새 게임 요청은 관리자 화면으로 접속한 연결만 처리합니다.
- **같은 규칙 코드를 서버와 브라우저가 함께 사용**: 이동 계산 코드를 TypeScript 하나로 작성해 양쪽에서 공유합니다.

## 끊김 없이 보이게 한 방법

- **내 캐릭터 즉시 반응(예측)**: 키를 누르면 서버 응답을 기다리지 않고 바로 움직이고, 서버 위치가 오면 조금씩 맞춥니다.
- **다른 캐릭터 부드럽게(보간)**: 약 0.1초 전 상태를 두 시점 사이에서 이어 그려, 네트워크가 들쑥날쑥해도 매끄럽게 보입니다.
- **입력은 바뀔 때만 전송**: 데이터 사용량을 줄여 무료 한도 안에서 운영합니다.
- **카운트다운 지연 보정**: 화면의 남은 시간에서 네트워크 편도 지연만큼을 빼서, 서버가 판정하는 순간 화면도 0이 됩니다.

## 끊겨도 다시 돌아오는 방법

- 입장할 때 서버가 본인에게만 **복귀 토큰**을 주고, 브라우저가 탭에 저장합니다.
- 게임 중 끊기면 서버가 15초 동안 자리·점수·색을 유지하고, 브라우저가 1.5초 간격으로 최대 12번 자동 재접속해 같은 자리로 돌아옵니다.
- 서버 소식이 8초 동안 안 오면 브라우저가 스스로 연결을 끊고 다시 붙습니다(와이파이 끊김은 브라우저가 늦게 알아채기 때문).
- 끊긴 채 판이 끝나도 최종 순위에 포함됩니다. 관리자 화면은 2초마다 계속 재접속합니다.

## 서버 보호

- 클라이언트 메시지는 초당 120개로 제한하고 형식을 검증합니다. 닉네임은 제어·서식 문자를 지우고 한글 기준 최대 5글자로 자릅니다.
- 입장 전 연결은 20개까지만 받고, 120초 안에 입장하지 않으면 끊습니다. 다른 사이트에서 여는 WebSocket은 Origin 검사로 막습니다.
- 로그인이나 입장 코드는 없습니다(가벼운 팀 게임).

## 그래픽

- 캐릭터(10가지 동작), 사무실 배경, 소품 6종은 **AI 이미지 생성 도구**로 만들었습니다.
- 생성된 이미지는 Node.js 스크립트(pngjs)로 초록 배경을 지우고, 동작별로 잘라서 씁니다.
- 캐릭터는 흰색 한 장만 그리고, 12가지 색은 **코드로 입힙니다**. 그래서 모든 캐릭터의 그림체가 같습니다.
- 타격 효과(번쩍임, 불꽃, 충격파, 흙먼지, 화면 흔들림), 굴러오는 통나무, 마지막 5초 붉은 화면과 큰 카운트, 시상식 연출(시상대, 왕관, 꽃가루, 꼴찌의 우는 연출)은 Canvas로 직접 그립니다.

## 비용

- Cloudflare 무료 플랜으로 운영합니다(하루 요청 10만 건 한도). 한 판에 약 725 요청이라 하루 100판 이상도 무료 범위입니다.
- 행사 중에는 배포하지 않고(서버가 재시작되면 전원이 끊기고 진행이 초기화됨), 행사 외 시간에는 관리자 탭을 닫아 무료 활성 시간을 아낍니다.
