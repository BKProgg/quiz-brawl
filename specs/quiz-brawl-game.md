## 1. 개요 (Overview)
* **배경 및 목적:** 팀원 10명 내외가 브라우저에서 2~3분 동안 가볍게 즐기는 업무 퀴즈 게임.
  단순 퀴즈의 지루함을 없애기 위해, 캐릭터들이 난투를 벌이며 바닥의 정답 구역을 차지하는 방식으로 진행한다.
* **유관부서 및 협업:**
- 요청 부서: 전자금융개발팀 (내부)
- 담당 PM: -

## 2. 요청 사항 (Requirements)
* [x] 브라우저에서 실행, 최대 10명 동시 접속, 아주 원활한 동작
* [x] 조작: 방향키(이동) + Z(주먹) / X(발차기) / C(막기), 붙어서 상대 방향 + Z = 머리 위로 들기, 다시 Z = 던지기
* [x] 캐릭터: 졸라맨처럼 단순하고 귀여운 2D 캐릭터, 모양은 같고 색(12색)만 다름
  (AI 생성 이미지 중 **선글라스 스타일**로 확정 — 2026-10-31 사용자 결정)
* [x] 입장: 닉네임(한글 기준 최대 5글자) 입력 후 캐릭터 선택 → 즉시 입장. 머리 위에 닉네임 항상 표시. 입장 시 조작 튜토리얼 표시
* [x] 진행: 자유 난투 → 문제 등장 → 잠시 후 바닥에 선택지 구역 생성 → 카운트 종료 시 정답 구역 안의 인원 득점
* [x] 굴러오는 통나무: 좌우 벽에서 주기적으로 나타나 경기장을 가로지름, 맞으면 날아가 쓰러짐 (막기로 못 막음)
* [x] 메테오: 문제마다 판정 5~8초 전에 한 번 떨어짐, 경기장 절반 범위, 맞으면 중심 반대 방향으로 날아가 1.5초 쓰러짐 (막기로 못 막음)
* [x] 재접속: 게임 중 끊겨도 잠시 자리·점수·색을 유지하고 같은 자리로 복귀
* [x] 문제 형식: OX, 4지선다
* [x] 시간·문제 수 등 수치는 모두 **설정값(변수)**으로 두어 나중에 변경 가능
* [x] 다굴(여러 명이 한 명 공격)은 허용, 연속 피격 시 다운 후 1초 무적만 둔다
* [x] 바닥에 잡동사니 아이템 배치: 아이템 위에서 Z = 줍기, 들고 있을 때 Z = 던지기, 직선상의 상대가 맞으면 자빠짐(다운)
* [x] 게임 종료 시 최종 순위 장면: 효과와 임팩트가 있는 연출, 이미지 포함

## 3. 수용 기준 (Acceptance Criteria)
* **AC 1:** 10명이 같은 방에 접속해 한 판을 끝까지 진행할 수 있다.
* **AC 2:** 방향키·Z·X·C 입력 시 브라우저 화면이 스크롤되지 않고, 한/영 입력 상태와 무관하게 동작한다.
* **AC 3:** 카운트 종료 순간 캐릭터 중심점이 정답 구역 위에 있는 플레이어는 상태와 상관없이 모두 득점한다.
* **AC 4:** 정답은 판정 시점 이전에 클라이언트로 전송되지 않는다.
* **AC 5:** 설정 파일의 수치만 바꾸면 시간, 문제 수, 전투 수치가 변경된다.
* **AC 6:** 아이템을 주워 던지면 직선으로 날아가고, 처음 맞은 상대는 다운된다.
* **AC 7:** 마지막 문제 판정 후 1~3위 시상 연출, 꼴찌 연출, 전체 순위표가 모든 플레이어 화면에 동시에 나온다. 최종 화면은 관리자가 새 게임을 누를 때까지 유지된다.
* **AC 8:** 게임 중 끊긴 플레이어가 `reconnectGraceSeconds`(15초) 안에 돌아오면 같은 캐릭터·점수로 복귀하고, 끊긴 채 판이 끝나도 최종 순위에 포함된다.

## 5. 배포 및 기술 참고사항 (Technical Notes)
* **영향 범위:** 독립 프로젝트 (사내 시스템과 연동 없음)
* **배포 시 특이사항:** Cloudflare Workers 무료 플랜 (Durable Objects SQLite 백엔드). 인증·비밀 값 설정 없음. `npx wrangler login` 후 `npm run deploy`
  - 방(Durable Object)은 처음 만들어진 위치에 고정되므로 `worker.ts`에서 `locationHint: 'apac'`으로 아시아에 만든다(이름 `main-apac`). 위치를 바꾸려면 이름을 바꾸면 된다
  - 실측(2026-11-01, 서울): 10명 게임 중 왕복 지연 중앙값 30~70ms. 다만 접속 경로가 가끔 홍콩·싱가포르·파리 센터로 잡혀 그 연결만 +200ms가 붙는다(서버가 아니라 Cloudflare 경로 문제, 새로고침하면 바뀜)
* **운영 수칙**
  - 행사 중에는 배포하지 않는다. 서버가 재시작되면 전원이 끊기고 진행 중인 판이 초기화된다.
  - 행사 외 시간에는 관리자 탭을 닫는다. 접속이 남아 있으면 Durable Object가 깨어 있어 무료 활성 시간을 쓴다.
  - 플레이어가 끊기면 브라우저가 자동으로 다시 붙는다. 그래도 안 되면 새로고침을 안내한다.
  - 무료 플랜 대략치: 한 판에 약 725 요청, 하루 100판 이상 가능.
* **참고 문서:** Cloudflare Durable Objects 요금 문서 (무료: 하루 요청 10만 건, 수신 WebSocket 메시지 20개 = 1건)

## 기술 설계

### 게임 규칙 상세

**한 판 진행 흐름**
1. 대기실: 닉네임 입력 후 캐릭터(12색)를 고르면 즉시 입장. 관리자 화면(`/admin`)에서 "게임 시작"을 누를 때까지 자유 난투로 연습 가능
2. 시작 카운트 (`introBrawlSeconds`, 화면 가운데 큰 숫자로 5초를 센 뒤 첫 문제)
3. 문제 등장 → 카운트 시작 (`answerCountdownSeconds`, 문제별 `countdownSeconds`로 덮어쓰기 가능)
4. 문제 등장 후 `zoneAppearDelaySeconds` 뒤 바닥에 선택지 구역 생성 (경기장을 꽉 채우는 격자, 구역 사이 통로 `zone.gap`. OX는 좌우 2칸, 4지선다는 2×2. 어느 칸에 어느 보기가 오는지는 문제마다 섞음)
   카운트 마지막 5초는 화면 가장자리가 점점 붉어지며 가운데에 큰 숫자(5-4-3-2-1)로 센다
5. 카운트 종료 → 서버 판정 → 정답 공개 (난투는 멈추지 않고 이어짐)
6. 사이 난투 (`betweenBrawlSeconds`) → 3번으로 돌아감 (총 `questionCount` 문제, 마지막 문제 뒤에는 `finalRevealDelaySeconds`)
7. 최종 순위 연출 → 관리자가 "새 게임"을 누를 때까지 최종 화면 유지 (시간이 지나도 자동으로 돌아가지 않음) → 새 게임을 누르면 전원 내보내고 처음 상태로
- 시작 전 대기실은 자유 난투다. 시작하면 점수만 초기화하고 위치·바닥 아이템은 대기실 그대로 이어진다.

**전투**
| 행동 | 입력 | 특징 |
|---|---|---|
| 이동 | 방향키 (8방향) | 마지막 이동 방향을 바라봄, 공격은 바라보는 방향으로 |
| 주먹 | Z | 빠름, 짧은 사거리, 작은 넉백 |
| 발차기 | X | 느림, 긴 사거리, 큰 넉백, 빗나가면 빈틈(`kick.missRecoverySeconds`) |
| 막기 | C 누르고 있기 | 주먹·발차기·아이템 다운 무효화, 이동 속도 감소. 통나무는 막을 수 없음 |
| 들기 | 몸이 닿은 상태에서 상대 방향키 + Z | 막기 무시, 상대를 머리 위로 든다. 드는 동안 느리게 걷고(`holdMoveSpeedRatio`) 방향을 바꿀 수 있다 |
| 던지기 | 들고 있는 동안 다시 Z | 바라보는 방향으로 던짐, 착지 시 다운. `holdSeconds`(1.5초) 안에 안 던지면 들린 사람이 빠져나옴. 잡은 직후 `minHoldSeconds`(0.15초)는 Z를 무시 |
| 아이템 줍기 | 아이템 위에서 Z | 머리 위로 들어 올림 (드는 동안 이동·발차기·막기 가능) |
| 아이템 던지기 | 아이템을 든 상태에서 Z | 바라보는 방향으로 직선 투척 |

- **Z 버튼 우선순위:** 사람을 들고 있음 → 던지기 > 아이템 들고 있음 → 아이템 던지기 > 상대와 붙어서 상대 방향키 → 상대 들기 > 아이템 위 → 줍기 > 주먹
- 상성: 타격 > 던지기(잡는 중인 사람을 때리면 풀려남), 던지기 > 막기, 막기 > 타격
- 끼어들기: 들린 사람은 아무것도 맞지 않고 잡히지도 않는다. 든 사람은 평소처럼 맞고 잡힌다. 든 사람이 주먹·발차기·아이템·통나무·메테오를 맞거나 다른 사람에게 잡히면 들린 사람은 그 자리에 안전하게 내려온다
- 풀려난 사람(탈출·끼어들기·든 사람 끊김)은 `releaseInvincibleSeconds`(1초) 동안 무적이라 바로 다시 잡혀 묶이지 않는다
- 같은 틱의 공격은 맞을 대상을 모두 모은 뒤 한꺼번에 적용한다 (동시에 때리면 둘 다 맞음)
- 체력 없음. 피격 시 넉백 + 짧은 경직만 발생
- 공격 자세는 타격 직후 바로 풀린다 (버튼을 떼면 즉시 원래 자세)
- `down.hitCount`회 피격이 `down.hitWindowSeconds` 안에 누적되면 뒤로 날아가 쓰러짐(다운 `down.durationSeconds`) → 기상 후 `down.invincibleSeconds` 무적
- 다굴 억제 장치는 두지 않는다
- 경기장은 고정 화면 (카메라 이동 없음, 10명 모두 한 화면에 보임)
- 이동 가능 영역은 배경 이미지의 책상·화분 장식 안쪽(`arena.left/right/top/bottom`)으로 제한한다

**메테오** (`meteor.*`, 문제 진행 중에만 등장)
- 문제마다 한 번, 판정까지 `minLandRemainingSeconds`~`maxLandRemainingSeconds`(5~8초) 남았을 때 착지하도록 그 `warningSeconds`(2초) 전에 경고가 시작된다. 맞은 사람이 판정 전에 돌아올 시간(공중 0.35 + 쓰러짐 1.5 + 복귀 약 1.1초)을 남기기 위한 값이다
- 경고는 정답 구역이 나온 뒤에 시작한다. 문제 시간이 짧으면 착지를 판정 쪽으로 당기고, 판정 5초 전도 남길 수 없으면(9초 이하) 그 문제에는 내지 않는다
- 위치는 정답과 무관한 무작위다. 반지름 350 원은 경기장의 약 46%를 덮고, 지름이 경기장 높이보다 커서 사실상 좌우로 피한다
- 착지 순간 한 번만 판정한다. 판정 원은 화면의 경고 원보다 캐릭터 반지름만큼 작다(내 화면이 서버보다 앞서 보이므로 경계에서 억울하게 맞지 않게). 캐릭터 중심이 그 안이면 중심 반대 방향으로 날아가 `downSeconds`(1.5초) 쓰러진다. 정중앙이면 바라보던 방향으로 날아간다. 막기 불가, 무적·공중·쓰러짐·잡힘 상태는 맞지 않는다
- 쓰러져 있는 동안 머리 위로 별이 돈다(모든 다운 공통, 화면 전용)

**굴러오는 통나무** (`log.*`, 대기실·진행 중 모두 등장)
- `log.minIntervalSeconds`~`log.maxIntervalSeconds`(10~20초)마다 좌우 벽 중 한쪽에서 거대한 통나무(세로 길이 `halfLength` 135 × 2)가 나타난다
- 나오기 전 `log.warningSeconds`(1초) 동안 벽에 경고가 표시되고, 이후 `log.speed`(330)로 반대편 벽까지 굴러간다
- 맞은 사람은 통나무 진행 방향으로 날아가 쓰러진다 (`log.launchSpeed`). 막기로 못 막고, 위아래로 피해야 한다
- 이미 공중·다운·잡힘 상태이거나 무적인 사람은 맞지 않는다

**판정 규칙**
- 카운트 종료 순간의 서버 상태로 판정
- 캐릭터 **중심점**이 정답 구역 안에 있으면 득점 (`scoring.pointsPerCorrect`)
- 상태는 보지 않는다. 맞거나 던져져 날아가는 중이어도, 들려 있어도, 쓰러져 있어도 중심점이 구역 위면 득점한다 (들린 사람은 든 사람과 거의 같은 위치라 경계에서는 갈릴 수 있음)
- 화면의 카운트다운은 편도 지연만큼 빼서 표시해, 서버 판정 시점에 화면도 0이 되게 한다

**캐릭터**
- AI로 생성한 선글라스 스타일 캐릭터 스프라이트(10개 동작)를 쓰고, 흰 몸통에 코드로 12가지 색을 입힌다
- 선글라스 스타일은 어몽어스 캐릭터를 떠올릴 수 있다는 의견을 전달했고, 사용자가 확정했다 (2026-10-31)
- 모든 캐릭터가 같은 모양이고 색만 다르다. 충돌 판정도 모두 동일한 원
- 입장 시 닉네임(제어·서식 문자 제거, 한글 기준 최대 `network.nicknameMaxLength` 5글자)을 입력하고, 이미 사용 중인 색은 고를 수 없다
- 머리 위에 닉네임을 항상 표시하고, 내 캐릭터는 흰 테두리 빛과 노란 이름표로 강조
- 입장하면 반투명 키보드 튜토리얼(방향키·Z·X·C)이 뜨고 10초 뒤 사라진다 (Esc/Enter로도 닫힘). 재접속 복귀 때는 다시 띄우지 않는다

**잡동사니 아이템**
- 사무실 잡동사니 6종 (머그컵, 키보드, 의자, 서류 뭉치, 화분, 고무 오리). 외형만 다르고 성능은 모두 동일
- 경기 시작 시 `item.initialCount`개를 랜덤 배치, **바닥에 놓인** 아이템이 `item.maxOnFloor`개 미만이면 `item.respawnSeconds`마다 1개 생성
- 던진 아이템은 직선으로 날아가며 **처음 맞은 상대 1명**만 다운시키고 소멸. 경기장 밖이나 `item.throwMaxDistance`에 도달해도 소멸
- 막기 중인 상대는 다운 없이 밀려나기만 함 (막기 > 타격 상성 유지)
- 던진 본인, 무적 상태, 이미 다운된 상대는 통과
- 아이템을 든 채 피격·다운되면 그 자리에 떨어뜨림

**최종 순위 연출** (마지막 판정 후 관리자가 새 게임을 누를 때까지 유지, 전원 화면 동기화, 난투 정지)
1. 무대 배경 + "최종 결과" 타이틀
2. 3위 → 2위 → 1위 순서로 공개: 캐릭터가 위에서 떨어져 시상대에 착지 (1위 착지 때 화면 흔들림, 점수 카운트업)
3. 1위: 스포트라이트, 왕관, 꽃가루 효과
4. 꼴찌: 조명이 왼쪽 아래로 옮겨 가 무릎 꿇고 엉엉 우는 모습에 먹구름과 비 (공동 꼴찌면 전원, 전원 동점이면 없음)
5. 전체 순위표 (최대 10명, 캐릭터 아이콘 + 닉네임 + 점수, 동점은 같은 순위). 끊긴 채 끝난 사람도 포함
6. 관리자 화면에 "새 게임" 버튼이 나타나고(확인 창 한 번), 누르면 플레이어 연결을 모두 끊고 방을 처음 상태로 되돌린다. 내보내진 플레이어 화면은 자동으로 다시 붙어 닉네임·캐릭터 선택부터 시작한다(관리자 연결은 유지)
7. 진행 중에는 같은 자리에 "게임 중단" 버튼이 있어(확인 창 한 번) 어느 단계에서든 같은 방식으로 처음 상태로 되돌릴 수 있다
- 캐릭터는 AI 생성 스프라이트, 시상대·왕관·꽃가루·조명은 Canvas로 그린다

**재접속**
- 입장할 때 서버가 본인에게만 복귀 토큰을 주고, 브라우저는 탭의 `sessionStorage`에 playerId와 함께 저장한다 (화면에 보이는 id만으로는 남의 자리로 복귀 불가). 토큰은 복귀해도 바뀌지 않고(바꾼 토큰이 담긴 응답을 받기 전에 다시 끊기면 돌아올 수 없게 되므로), 토큰이 틀린 요청은 거절만 한다
- 서버는 `network.silenceTimeoutSeconds`(70초) 동안 아무 메시지(2초 간격 ping 포함)가 없는 연결을 죽은 것으로 보고 먼저 끊어 유예 처리에 넣는다 (절전에서 잠깐 깨어난 사람이 그대로 이어 하도록 넉넉히 둠). 그보다 먼저 `network.keyReleaseSilenceSeconds`(10초) 동안 소식이 없으면 누르고 있던 방향키·막기를 뗀 것으로 보아, 조용히 끊긴 사람의 캐릭터가 마지막 입력대로 계속 달리지 않게 한다(버튼 횟수는 유지)
- 게임 중 끊기면 서버가 `network.reconnectGraceSeconds`(15초) 동안 자리·점수·색을 유지한다
- 브라우저는 1.5초 간격으로 최대 12회(실패를 바로 알 수 있으면 약 18초, 응답 없는 네트워크에서는 시도마다 4초를 더 기다려 약 66초) 자동 재접속해 같은 자리로 복귀한다. 연결 시도 하나는 4초 안에 열리지 않으면 버리고 다음 시도로 넘어간다(응답 없는 네트워크에서 브라우저가 1분 넘게 기다리는 것 방지). 처음 접속과 관리자의 방 초기화 뒤 재연결도 같은 방식으로 여러 번 시도하고, 12회를 다 실패한 뒤에는 화면을 누르거나·키를 누르거나·탭이 다시 보일 때 12회를 다시 시도한다. 서버 메시지(핑 응답 포함)가 8초 동안 안 오면 스스로 연결을 끊고 재접속한다 (와이파이 끊김 대비). 이 감시는 플레이어·관리자 화면 공통(NetworkClient)이며, 감시 타이머 자체가 늦게 돌았으면(탭 숨김·화면 멈춤) 그 공백은 끊김으로 보지 않는다
- 캐릭터 선택 화면에서 끊겨도 같은 방식으로 자동 재접속해 바로 다시 고를 수 있다. 이를 위해 서버는 입장 전 연결의 핑에도 pong을 답한다(입장 전에는 다른 명령은 받지 않음). 단, 입장 시간 초과(120초, close 사유 `join timeout`)로 끊긴 탭은 열어만 둔 탭이 서버를 계속 깨워 두지 않도록 바로 붙지 않고, 화면을 누르거나·키를 누르거나·탭이 다시 보일 때 붙는다 방이 가득 차 거절됐거나 다른 탭에 자리를 넘긴 경우에만 재접속하지 않는다
- 핑은 2초 타이머 외에 서버 메시지를 받을 때마다(2초 경과 시) 보낸다. 숨긴 탭은 타이머가 늦춰지지만 메시지 수신은 늦춰지지 않으므로, 게임 중인 탭은 숨겨져 있어도 서버의 무응답 기준(70초)에 걸리지 않는다
- 끊긴 채 판이 끝나도 최종 순위에 포함된다. 유예가 지나면 완전히 퇴장하며 이때 점수도 사라진다
- 같은 자리로 다른 탭이 들어오면 옛 탭은 물러나고 다시 붙지 않는다
- 대기실에서 끊기면 바로 나간다 (새로고침하면 다시 선택)
- 관리자 화면은 끊기면 2초마다 무한 재접속한다

### 기술 스택 (확정)
- **서버:** Cloudflare Workers + Durable Objects (방 1개 = Durable Object 1개, 서버 권한 구조)
- **클라이언트:** TypeScript + Canvas 2D (프레임워크 없음), esbuild로 번들, 같은 Worker에서 정적 파일 서빙
- **넷코드:** 클라이언트는 입력만 전송(변경 시에만). 서버가 이동·전투·판정을 계산한다.
  - 내 캐릭터 이동은 클라이언트에서 예측하고, 서버 위치로 보정한다.
  - 공격 키를 누르면 예측을 잠시 멈추고, 다른 캐릭터와는 겹치지 않게 처리한다.
  - 자유 상태가 아닐 때는 보간 위치로 그린다.
  - 다른 캐릭터는 약 100ms 보간한다. 스냅샷 시각은 시뮬레이션 시각(틱 × 틱 길이)으로 보낸다.
  - 화면의 카운트다운은 편도 지연(왕복의 절반)만큼 빼서 서버 판정 시점에 0이 되게 한다.
  - 30Hz 시뮬레이션, 20Hz 스냅샷 전송. 클라이언트 메시지는 초당 120개로 제한한다.
- **이미지:** AI 생성 원본(`assets-source/`)을 `npm run assets`로 가공해 `public/assets/`에 저장한다.
  가공 내용은 배경 제거, 동작별 자르기, 워터마크 정리다.
- **테스트:** Vitest

### 메시지 규약 (요약)
- 클라이언트 → 서버: `join {nickname, colorIndex}`, `resume {playerId, resumeToken}`, `adminJoin`,
  `input {isUpPressed, isDownPressed, isLeftPressed, isRightPressed, isBlockPressed, punchCount, kickCount}`,
  `start`, `newGame` (`start`·`newGame`은 관리자 연결만 처리), `ping {clientTime}`
- 서버 → 클라이언트: `welcome {playerId, resumeToken, config}`, `adminWelcome {config}`,
  `rejected {reason: roomFull | colorTaken | resumeExpired | invalidNickname | invalidJoin}` (`roomFull` 외에는 연결을 유지),
  `roster {players[]}`, `snapshot {serverTime, phase, phaseRemaining, players[], items[], logs[], meteors[]}`,
  `question {question | null}`, `zones {zones[]}`, `judged {answerIndex, scorerIds, scores}`, `finalResult {rankings[]}`, `pong`
- 복귀 토큰(`resumeToken`)은 `welcome`으로 본인에게만 전달되고 `roster`·`snapshot`에는 실리지 않는다.
- 버튼은 누른 횟수(`punchCount`, `kickCount`)로 보내, 틱 사이에 짧게 누른 입력도 놓치지 않는다.
  서버는 첫 입력을 기준값으로만 쓴다.

## 리스크
- 보안
  - **입장:** 가벼운 팀 게임이라 인증·입장 코드를 두지 않는다. 주소를 아는 사람은 누구나 입장할 수 있다. 관리자 기능(`start`, `newGame`)은 `adminJoin`한 연결만 처리하지만 `/admin`에도 인증은 없다.
  - **자리 보호:** 복귀는 입장 때 본인에게만 준 토큰이 있어야 하고, 화면에 보이는 playerId만으로는 남의 자리로 복귀할 수 없다.
  - **무료 한도 보호:** 입장 전 연결은 20개로 제한하고, 120초 안에 입장하지 않으면 끊는다. 입장 전에는 입장·복귀·핑 외의 명령은 처리하지 않는다(형식이 틀린 요청에는 `invalidJoin`으로 답한다).
  - **입력 제한:** 메시지는 초당 120개(넘으면 연결을 끊음), 2KB로 제한하고, 타입·범위를 검증한다.
  - **연결 보호:** Origin 검사로 다른 사이트에서 여는 WebSocket(CSWSH)을 막는다.
  - **닉네임:** 제어·서식 문자를 제거하고, 화면에는 textContent와 fillText로만 넣는다.
  - **정답 보호:** 정답은 판정 후에만 전송한다.
  - **문제 내용:** 민감한 업무 정보(시스템 구조, 계정, 고객 정보)는 문제로 쓰지 않는다.
- 사내 정책: 회사 관련 내용을 외부 무료 호스팅에 올려도 되는지 확인 필요
- 무료 한도: 입력은 변경 시에만 전송해 하루 요청 수 한도 안에서 운영한다(한 판 약 725 요청). 초과 시 월 $5 유료 플랜
- 서버 재시작: 행사 중 배포하면 전원이 끊기고 진행 중인 판이 초기화된다 (방 상태는 메모리에만 있음). 배포 주소 실측에서 배포와 `wrangler tail` 연결 모두 약 5분 뒤에 Durable Object가 재시작됐다(전 연결 1006 종료, 방 초기화). 둘 다 없던 실행에서는 재시작이 없었다
- 개별 연결 끊김: 배포 주소 실측에서 게임 중 연결 하나가 비정상 종료(1006)되는 일이 판당 0~3건 있었다(게임 코드와 무관한 대조용 연결에서도 발생). 자동 재접속으로 1.5초 뒤 같은 자리에 복귀한다
- 캐릭터 저작권: 선글라스 스타일이 기존 게임 캐릭터를 연상시킬 수 있다 (사용자 확정 사항)
- 남은 개선점
  - 닉네임 중복 허용
  - 이미지 하나만 로드에 실패해도 게임이 시작되지 않음
  - 붙어서 동시에 잡기를 누르면 먼저 처리된 사람이 잡음
  - 정원(10명)에는 유예 중인 사람도 들어간다. 10명이 찬 게임 중 탭을 닫고 새 탭으로 오면 15초 동안 `roomFull`이고, 그 뒤 들어와도 그 판은 구경한다
  - 달리다 발차기하면 내 화면의 캐릭터가 서버보다 최대 약 50px 앞서 나갔다가 부드럽게 끌려온다(예측 멈춤 시간이 발차기 시간보다 짧음)
  - 관리자의 새 게임·중단 확인 창을 70초 넘게 띄워 두면 관리자 연결이 끊겨 명령이 사라진다(다시 붙은 뒤 한 번 더 누르면 됨)
  - 키를 누른 채 화면이 10초 넘게 멈췄다가 재접속 없이 이어지면, 서버는 키를 뗀 것으로 알고 브라우저는 누른 줄 안다. 아무 키나 누르거나 떼면 다시 맞는다
  - 관리자 화면의 참가자 수에는 캐릭터 선택 화면에 머무는 사람이 보이지 않는다. 시작하면 그 사람은 그 판을 구경만 한다
- 범위 외(프로토타입): 사운드, 문제 편집 화면, 모바일 터치 조작, 관리자 인증
